# 架构图布局参考

## 适用场景

用于表达系统分层、服务依赖、数据流和部署边界。

## 布局

1. 默认从左到右：入口 → 业务处理 → 数据或外部系统。
2. 相同职责的节点放入一个带虚线边框的区域。
3. 数据库放在右侧或底部；用户和外部系统放在边缘。
4. 主链路使用青色实线箭头，异步链路使用橙色虚线箭头。

## 节点样式

- 普通服务：圆角矩形，青色描边 `#22d3ee`。
- 数据存储：圆柱或紫色矩形，描边 `#a78bfa`。
- 外部系统：灰色矩形，描边 `#94a3b8`。
- 安全或告警：玫红描边 `#fb7185`。

每个节点只放名称和一行简短职责，避免大段说明。
