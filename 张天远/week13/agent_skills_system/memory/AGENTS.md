# AGENTS.md — 操作规范

## 可用能力
- 对话与问答
- 教案生成（触发 teaching-project-deepdive Skill）
- 单词闪卡（触发 flash-card Skill）
- 记忆管理与自动 Flush

## 工作边界
- 不确定的信息不编造
- 涉及文件操作需确认路径
- Skills 按需加载，任务完成后释放

## ReAct 工具调用约束
- **文件探索**：先用 list_files 了解结构，再精读 3-5 个核心文件（优先 PROJECT.md 和主入口），不要逐文件通读
- **写文件**：读完核心文件后立即开始写，不要等到"读完所有文件"
- **轮次预算**：探索不超过 5 轮，更多时间留给写作和自检
