# 全流程实操手册 阶段模板

> 核心原则：**每关必须告诉学生"屏幕上会看到什么"，以及"如何判断成功"**。
> 薄弱学习者最大的恐惧不是跑不动，而是跑完了不知道对不对。

## 模板

```markdown
### 阶段 N：阶段名称（预计时间）

\`\`\`bash
# ✅ 关X：任务名
python src/script.py --arg1 val1 --arg2 val2
# 预期输出：
#   KeyLine1: value1
#   KeyLine2: value2
#   图表/文件生成到 outputs/xxx
#
# 判断成功：[具体的判断标准，不是"运行不报错"]
#   例如：val_f1 > 0.65 → 模型在学习
#   例如：阈值从 0.55 降到 0.51 → 越来越自信
#   例如：epoch 1→3 F1 跳升 0.10 → 模型需要 3 epoch 才能表现真实水平

# ✅ 关X+1：下一个任务
python src/next_script.py
# 预期输出：...
# 判断成功：...
\`\`\`
```

## 五个阶段（标准分配）

| 阶段 | 内容 | 学生心态 |
|------|------|---------|
| 阶段 0 | 环境验证（GPU/CUDA/依赖/数据） | "我能跑吗？" |
| 阶段 1 | 数据探索 + 最简单基线 | "数据长什么样？传统方法能做到什么程度？" |
| 阶段 2 | 核心训练（2-3 个模型） | "深度学习比传统方法好多少？" |
| 阶段 3 | 对比分析 + Bad Case | "哪个最好？为什么？错在哪？" |
| 阶段 4 | 消融实验（选跑） | "改这个参数会怎样？" |
| 阶段 5 | 扩展实验（选跑） | "还有什么花样？" |

## 判断成功的写法

| ❌ 差 | ✅ 好 |
|------|------|
| `# 判断成功：运行不报错` | `# 判断成功：val_f1 > 0.65；阈值从 0.55 降到 0.51` |
| `# 判断成功：train_loss 下降` | `# 判断成功：epoch 1 loss ~0.10, epoch 3 loss ~0.07` |
| `# 判断成功：模型保存成功` | `# 判断成功：val_f1 每 epoch 微涨；最优 checkpoint 已保存到 outputs/` |
