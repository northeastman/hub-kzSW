# Week05 教案生成复盘

## 事实错误：参数量 36M vs 102M

**症状**：教案全文引用的参数量为 ~36M，但 config.py 实际默认值（HIDDEN_SIZE=768, NUM_HIDDEN_LAYERS=12）下模型为 ~101.7M。

**根因**：`gpt_model.py` 中 `GptConfig` 类的默认值（hidden_size=512, num_layers=8）和 `config.py` 模块默认值不同。教案直接引用了代码注释中的数字（注释基于类默认值），未验证 config.py 的实际生效值。

**修复**：
- 手动分组件计算：Embedding 16.6M + Decoder(12层×7.09M) 85.0M = 101.7M
- 全文 14 处替换 36M→102M
- 修正关联数字：百分比(30%→16%)、ChatGPT倍数(5000×→1700×)、训练时间(2-4h→4-8h)

**已内化到 skill**：阶段 1 新增第 11 步"数值声明验证"；常见错误表新增对应条目。

### 3. Mermaid 语法错误
**症状**：附录 C 的 Mermaid 图中 `B_POOL[[CLS]→Pooler→Tanh]` 渲染失败，报 `Parse error: Expecting 'SUBROUTINEEND'`。
**根因**：Mermaid 的 `[[...]]` 是 subroutine 节点形状，`→` 在内部被解析为边语法。
**修复**：改为 `B_POOL["[CLS] Pooler Tanh"]`。
**已内化到 skill**：常见错误表新增对应条目。

### 4. 技巧专题打断主流程
**症状**：第九章"技巧专题"插在步骤7（生成）和评估之间，学生正跟着主线图走，突然被"AMP的三个开关"打断。
