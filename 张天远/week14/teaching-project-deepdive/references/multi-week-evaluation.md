# 多周系列教案质量评估框架

当为一个课程产出多周教案后（如 Week03→Week04→Week05），用此框架评估递进是否平滑。

## 五轴评估

### 轴 1：概念密度曲线

统计每周教案的净新概念数（排除标记为"复习"的概念），画出曲线。

- **理想**：每周净新概念数在 7-12 个之间，周与周之间波动不超过 ±30%
- **警觉**：某周净新概念 >15 个 → 考虑拆成两周或降级部分概念为辅助
- **示例**：Week03(14新) → Week04(~10净新) → Week05(~10净新) = 密度平稳

### 轴 2：最大跳跃点

找出概念抽象度跃升最大的周次。通常是从"串行处理"到"并行注意力"的范式转换。

- **检查项**：该跳跃点的教案是否做到了——
  - a. 跳跃前的复习引用充分（📎 复习 + 一句话 + 回链）
  - b. 跳跃概念被拆解为多个子步骤讲解
  - c. 每个子步骤有自己的类比
  - d. 公式走了 R8 四步（尤其是数值代入实例）
- **如果上述任一项缺失**：该跳跃点有风险

### 轴 3：代码复杂度曲线

统计每周教案中引用的代码总行数（不含注释和空白），以及最大单文件行数。

- **理想**：总代码行数逐周递增但不过快（+50-100%/周），最大单文件不超过 800 行
- **警觉**：某周代码量突然爆炸（+200%）→ 检查是否过度贴了完整文件而非最小有效片段

### 轴 4：隐喻一致性

检查三周的隐喻是否各自精准（R3 checklist），以及隐喻切换是否有预告。

- **理想**：每个隐喻精准映射该周核心范式；切换有提前预告（在上一周结尾的 🔙 中）
- **警觉**：学生每周切换一个完全不同的心理场景可能造成认知负担——如果三周内容有共同的抽象层，优先考虑统一隐喻
- **但不要强行统一**：LSTM/BERT/GPT 三种范式差异太大，强行统一反而扭曲概念

### 轴 5：认知过载风险

检查每周教案的"可选阅读"比例和深度版特有内容的标注。

- **理想**：每周至少有一处明确标注"可选"的内容（技巧专题、子项目、扩展阅读），让学生知道"跳过这里也能理解核心"
- **警觉**：深度版特有内容（L2/L3 实验、扩展阅读）在主流程中未加标注，学生可能以为必须全部掌握

## 快速评估清单

- [ ] 每周前置要求中的"已知"是否准确覆盖了前几周的实际教学内容？
- [ ] 每周的净新概念数是否在 7-12 之间？
- [ ] 最大跳跃点的教案是否有子步骤拆解 + 类比 + 数值实例？
- [ ] 代码引用是否遵守最小有效片段原则（没有贴 50 行只讲 3 行）？
- [ ] 隐喻切换是否有上一周的提前预告？
- [ ] 可选内容是否明确标注？
- [ ] 跨周 🔜回收 是否全部在正文中（不在 Q&A 中）？
- [ ] 每周结尾的 🔙 是否预告了下一周？

## 实战案例：Week03-05 评估

| 轴 | 评分 | 说明 |
|------|------|------|
| 概念密度 | ✅ 良好 | 净新概念平稳（14→10→10），复习引用机制让跳跃感降低 |
| 最大跳跃点 | ⚠️ 可接受 | LSTM→Attention 是范式跃迁，分解为 4 子步骤 + 类比 + 数值实例后通过 |
| 代码复杂度 | ✅ 良好 | 逐周递增（500→1000→1800行），最小有效片段原则控制得好 |
| 隐喻质量 | ✅ 良好 | 三周隐喻各自精准（快递分拣→阅读考试→故事接龙），切换有提前预告 |
| 认知过载 | ⚠️ 修复后通过 | Week05 采样策略密集 + 技巧专题原在主流程中 → 采样加流水线图 + 技巧移至文末扩展阅读 |
