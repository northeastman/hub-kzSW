# Multi-Week Redundancy Check

> 生成新一周教案前必须执行，避免重讲学生已学过的内容。

## 步骤

### 1. 收集前几周已教概念清单

搜索前几周教案的以下标记：

```
- 章节标题（## 步骤 N）
- ★新 / **新** 标记
- 🛠 动手实验
- 概念速查表中的条目
```

### 2. 画重叠矩阵

| 概念 | Week03 | Week04 | Week05 | Week06 | 处理 |
|------|--------|--------|--------|--------|------|
| Tokenization | | ✓ BERT | ✓ MyGPT | 要讲？ | → 📎 Week05 |
| BERT 架构 | | ✓ 整节 | | 要讲？ | → 📎 Week04 |
| 训练循环 | | | ✓ 整节 | 要讲？ | → 📎 Week05 |
| 分层学习率 | | | | ✓ 首次 | → 完整讲 |
| LoRA | | | | ✓ 首次 | → 完整讲 |

### 3. 决策：砍掉还是 📎

- **已有整节教学** → 新教案中用 `📎 WeekN 第 X 节` 一句话回链
- **已提过但未深入** → 新教案中只讲"新技巧"，基础假设学生已懂
- **全新概念** → 完整 R1 四步解释

### 4. 结构重排

砍掉冗余后，新知识可能在原有结构中散落各处。重新编排使新知识连续、不被打断。

## 输出格式

在新教案开头加「零、前置回顾」节：

```markdown
## 零、前置回顾：你已经知道的

| 概念 | 一句话 | 来源 |
|------|--------|------|
| Tokenization | 文本→数字ID | 📎 Week04 第2节 |
| BERT = 12层 Encoder | 双向看上下文 | 📎 Week04 第3节 |
...

> 如果对上面概念熟悉，往下读。本周重点是 XXX（全新）。
```
