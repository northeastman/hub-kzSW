# 增量实验分层设计

## 核心原则：位置 > 数量

不是所有数据集 × 所有方法的笛卡尔积都值得跑。**每个新增实验必须回答一个独有的分析问题**。

## 四层递进结构

```
L1 核心实验（必做）
  └─ 建立基线：传统方法 + 3种训练范式 + 对比+BadCase
     → 30-40 min，产出完整的对比矩阵

L2 消融实验（选做，建议全跑）
  └─ 单变量控制：池化/层数/epoch/margin——每个只变一个参数
     → 每项 2-10 min，产出 F1 曲线

L3 跨数据集（第二战场）
  └─ 不是复制 L1+L2——只跑"数据规模变化后最有看点的实验"
     └─ 例子：LCQMC Triplet（验证"大数据下 Triplet 优势"）
     └─ 例子：3×3 迁移矩阵（量化领域泛化）
     → 每项 5-30 min

L4 高级扩展（加分项）
  └─ 每个实验对应教案中一个 PPT 专题
     └─ SimCSE、Hard Neg、Few-shot、混合训练、FAISS
     → 每项 3-25 min
```

## 三层判断——加不加一个实验

对每个候选实验问三句话：

1. **回答了哪个分析问题？**——不能是"看下效果"，必须是"验证 XYZ 假设"或"量化 ABC 差异"
2. **有没有更简单的方法得到同样结论？**——如果已有实验的日志里就能提取（如 1-epoch F1 从 3-epoch log 里拿），不跑
3. **放哪个数据集上？**——优先放在"规模/领域差异最大"的数据集上

## 典型反例

| 反例 | 为什么不对 | 正确做法 |
|------|-----------|---------|
| BQ 跑全套 15 个实验 | 和 AFQMC 同属金融，80% 冗余 | 只跑 BM25/BiCosine/BiTriplet，核心价值在 3×3 迁移矩阵 |
| LCQMC 跑 Hard Neg | 概念已在 AFQMC 上演示了 | 跳过 |
| 数据消融在 AFQMC 上跑 | 只有 34K，最多三档 | 只在 LCQMC（238K）上跑六档曲线 |

## 实验数膨胀的根因

每次"加上这个"之前没问"它回答什么问题"。解决：在加实验的同时补一句话注释（如 `# 验证 TripletLoss 在 70K 三元组下的优势`），后续审查时一眼能看出哪些是"必跑"哪些是"凑数"。

## 实验报告的天然结构

四层递进直接映射到报告章节：

1. **基线对比**（L1）→ "哪种方法最好"
2. **消融分析**（L2）→ "为什么好、哪些参数关键"
3. **跨数据集泛化**（L3）→ "好在哪、不好在哪"
4. **高级方案**（L4）→ "还有什么可能性"
