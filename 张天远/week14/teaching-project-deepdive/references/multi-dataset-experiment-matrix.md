# 多数据集实验矩阵扩展

## 核心原则

> 当项目有多个数据集时，所有实验方法必须在全数据集上复制——除非某个实验在特定数据集上有明确的不可行理由。

**反例（Week08 踩坑）**：AFQMC 上设计了 SimCSE/两阶段/LLM 实验，但 LCQMC 上只跑了 BiCosine。用户质问"为什么这些不在 LCQMC 上跑？"——没有正当理由，就是遗漏。

## 矩阵扩展清单

收到项目后，对每个**实验方法**和**数据集**做矩阵检查：

```
          Method
Dataset    BM25  BiCos  BiTri  Cross  SimCSE  TwoStage  LLM  ...
AFQMC      ✓     ✓      ✓      ✓      ✓       ✓         ✓
LCQMC      ✓     ✓      ✓      ✓      ✓       ✓         ✓  ← 必须全列
```

**检查规则**：
1. 如果某一格为空，必须有明确的排除理由（如"LLM 需要 API key，云上不可用"）
2. "数据太大数据集跑太慢"不是理由——可以减 epoch 或采样
3. 每个数据集独有的实验（如数据消融需要大数据集）单独列出

## 不需要复制的例外

| 实验类型 | 不复制到其他数据集的理由 |
|---------|------------------------|
| 数据规模消融 | 只需要一个大数据集做 scaling |
| 领域迁移 | 本身就是跨数据集的，不需要"再跨一次" |
| 混合训练 | 固定方向（大→小），不需要双向 |
| 需要 API key 的 | 云上通常没有，线下可选跑 |
