# 商品需求分析与购买决策 Skill

## Skill名称

**真实场景驱动的商品筛选与购买决策分析 Skill**

---

# 一、适用场景

用于分析以下类型商品：

* 家电
* 数码产品
* 户外装备
* 厨具
* 家居用品
* 工具设备
* 运动装备
* 汽车用品
* 其他需要购买决策的商品

目标：

不是寻找“最贵”或“销量最高”的商品，而是找到：

> 在用户真实使用场景下，综合性能、价格、可靠性、长期使用价值最高的产品。

---

# 二、分析流程总览

完整流程：

```
用户需求分析
        ↓
使用场景建模
        ↓
确定核心指标权重
        ↓
市场热门产品筛选
        ↓
销量/评价/参数综合分析
        ↓
拆解商品详情页卖点
        ↓
分析真实用户反馈
        ↓
识别常见缺陷
        ↓
价格价值分析
        ↓
建立产品梯队
        ↓
给出最终购买建议
```

---

# 三、第一步：需求画像分析

不要直接推荐商品。

首先提取用户需求：

## 1. 使用者

例如：

* 单人
* 情侣
* 家庭
* 老人
* 儿童
* 专业用户

## 2. 使用场景

明确：

* 使用频率
* 使用地点
* 环境条件
* 使用时间
* 是否移动
* 是否长期保存

例如：

错误：

> 推荐40L保温箱

正确：

> 一家三口、自驾露营、夏季、1～3天，需要保存肉类和饮料。

---

## 3. 使用周期

判断：

* 临时使用
* 偶尔使用
* 高频使用
* 专业使用

---

## 4. 用户隐含需求

主动挖掘：

例如：

用户说：

“家庭露营”

实际需求可能包含：

* 容量不能太小
* 搬运不能太困难
* 清洗方便
* 以后还能升级
* 家人愿意使用

---

# 四、第二步：建立购买指标权重

根据场景调整权重。

不要固定评价体系。

例如：

## 家庭户外装备：

权重：

| 指标   | 权重  |
| ---- | --- |
| 实际体验 | 30% |
| 可靠性  | 25% |
| 性价比  | 20% |
| 便利性  | 15% |
| 颜值   | 10% |

---

## 专业工具：

调整为：

| 指标  | 权重  |
| --- | --- |
| 性能  | 40% |
| 耐用性 | 30% |
| 可靠性 | 20% |
| 价格  | 10% |

---

# 五、第三步：筛选候选产品

候选来源：

* 淘宝/京东热销款
* 品牌旗舰产品
* 用户评价高产品
* 专业用户推荐产品

筛选：

至少包含：

## 低价代表

了解最低成本方案。

## 主流价位代表

寻找性价比。

## 高端代表

判断高价是否值得。

---

# 六、第四步：商品详情页拆解

不要只看宣传参数。

重点分析：

## 产品定位

回答：

这款产品给谁设计？

例如：

* 入门
* 家庭
* 专业
* 极限环境

---

## 核心技术

分析：

哪些参数真正影响体验。

例如：

保温箱：

不能只看：

“72小时保冷”

而应该看：

* 箱壁厚度
* PU发泡
* 密封结构
* 冷源容量

---

## 宣传真实性判断

区分：

营销参数：

例如：

“旗舰级”

“专业级”

“超长续航”

实际指标：

例如：

* 容量
* 重量
* 材料
* 结构

---

# 七、第五步：用户真实反馈分析

重点分析：

## 好评：

寻找：

用户为什么满意。

例如：

* 好用在哪里
* 哪些场景表现优秀

---

## 差评：

不要简单统计差评数量。

重点分类：

### 设计缺陷

例如：

容量不足。

### 使用误区

例如：

冰袋太少导致保冷差。

### 产品缺陷

例如：

结构损坏。

---

# 八、第六步：价格价值分析

不要问：

“哪个最便宜？”

而问：

“多花的钱买到了什么？”

建立：

## 价格提升 → 价值提升模型

例如：

100元：

基础可用

300元：

明显提升体验

500元：

提升耐久和极端性能

1000元：

专业场景价值增加

判断：

价格增加是否值得。

---

| --- | -- | -- | -- | ---- | -- |
| 产品A |    |    |    |      |    |
| 产品B |    |    |    |      |    |
| 产品C |    |    |    |      |    |

---

# 十、第八步：场景模拟测试

不要只比较参数。

模拟真实使用。

格式：

## 场景：

例如：

一家三口夏季露营2天。

分析：

* 能否满足
* 会遇到什么问题
* 是否需要额外配件

---

# 十一、第九步：最终推荐规则

最终输出：

## 第一推荐

适合：

大多数用户。

特点：

* 平衡最好
* 风险最低
* 性价比最高

---

## 第二推荐

适合：

预算更高或特殊需求。

---

## 第三推荐

适合：

明确偏好用户。

---

# 十二、购买建议格式

最终答案必须包含：

## 1. 推荐型号

明确：

品牌 + 型号 + 规格

---

## 2. 推荐理由

说明：

为什么适合用户。

---

## 3. 不推荐原因

告诉用户：

哪些产品为什么不要买。

---

## 4. 配套建议

例如：

* 配件
* 使用技巧
* 注意事项

---

# 十三、禁止事项

分析商品时避免：

❌ 只看销量

❌ 只看参数

❌ 只推荐最高价

❌ 编造不存在的评价

❌ 把营销宣传当实际体验

❌ 忽略用户使用场景

# Skill核心原则

永远遵循：

> 先理解人，再分析商品；先分析场景，再比较参数；先判断价值，再推荐价格。

优秀的购买建议不是找到“最好的商品”，而是找到：

> 对这个用户而言，最值得购买的商品。
