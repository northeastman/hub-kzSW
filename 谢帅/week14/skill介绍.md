# work-summary-dashboard 技能介绍

一句话：**把一份月度日志报告（.xls / .xlsx）自动整理成一页可直接打开、打印或交给领导的 HTML 工作总结看板。**

---

## 一、这个技能解决什么问题

每月写工作总结是件麻烦事：日报是零散的流水账，总结却要求条理清晰、有重点、有数据、有自我评价。手工整理既费时又容易遗漏。

这个技能把整个过程自动化：

```
日志报告.xls  ──▶  提取数据  ──▶  归纳成主线  ──▶  生成 HTML 看板
```

产出是**单个 `.html` 文件**，样式全部内联，不依赖任何外部资源，双击即可打开，也能直接打印成 PDF。

---

## 二、触发场景

只要涉及「把日志 / 日报变成总结或看板」，都会触发，例如：

- 「根据这个报告生成工作总结」
- 「把日志做成一个 HTML 页面」
- 「做个月度工作总结 / 看板 / dashboard」
- 「生成绩效汇报页面」

即使没有明确说「dashboard」，只要是对着日志报告要总结/看板，都会启用。

---

## 三、工作流程（四步）

### 第 1 步 · 定位并读取报告
运行内置的提取脚本 `scripts/extract_report.py`，它会：
- 通过**列目录**的方式找到文件，避免中文路径在命令行里乱码
- 自动识别旧版 `.xls`（用 xlrd 引擎）和新版 `.xlsx`（用 openpyxl 引擎）
- 强制 UTF-8 输出，防止 Windows 控制台中文乱码
- 打印出每一个非空单元格，作为唯一的「事实来源」

### 第 2 步 · 归纳内容（核心价值所在）
把零散日报整理成一个连贯的故事：
- **头部 4 个 KPI**：总工时、任务完成率、工作量偏差率、有效日报数——全部取自报告真实数字
- **2~4 条工作主线**：把日报聚类成本月主要工作方向，每条配标题 + 3~4 条成果
- **三个独立模块**：`AI 提效分享` / `额外贡献` / `技术体系梳理沉淀`——这三项对应考核指标，单独成块，不混进主线
- **自我评价**：3~5 条基于事实的评价 + 改进方向

### 第 3 步 · 生成 HTML
基于 `assets/template.html` 模板，逐段替换成真实数据，保持统一的视觉风格。

### 第 4 步 · 结构校验
自动检查 `<style>` / `<script>` / `<div>` 等标签是否成对闭合，防止多段编辑漏掉闭合标签导致页面错乱。

---

## 四、视觉风格（数据看板风）

一套沉淀下来的「BI 看板」审美，关键约定：

| 要素 | 说明 |
|------|------|
| 底色 | 浅灰底 + 白色卡片，干净不刺眼 |
| 配色 | 靛蓝 / 青绿 / 琥珀 / 玫红 / 天蓝，**一个数据系列固定一个颜色** |
| 数字 | 所有有意义的数字用等宽字体（tabular-nums），这是「看起来像看板」的关键 |
| 布局 | 顶栏横幅 → 4 个 KPI 卡 → 环形图 + 进度条 → 工作主线卡 → 三个模块 → 自我评价 → 页脚 |
| 动效 | 滚动淡入（尊重「减少动态效果」偏好），响应式，打印友好 |

---

## 五、最重要的一条铁律：数据诚实

> **只呈现报告里真实支持的内容，绝不编造 KPI 或模块。**

- 报告里没有的模块，**宁可删掉，也不硬凑**。
- 如果某个数字是估算（比如并行工作日导致的分布重叠），在提示文字里如实标注，不冒充精确值。

**实测案例**：6 月的报告里没有「额外贡献」、没有明确的 AI 分享事件、也没有 ShowDoc 产出。技能没有硬套 7 月那套三模块结构，而是：
- 删掉了「额外贡献」模块
- 把 AI 模块降级为据实的「AI 应用落地」（写真实的图片合规审核业务）
- 把「AI 分享 ≥1 次/月」「ShowDoc 整理」缺失的情况，如实写进了改进方向

这正是这条铁律在起作用。

## 六、技能文件结构

```
work-summary-dashboard/
├── SKILL.md                      # 主文件：触发描述 + 四步流程 + 红线
├── scripts/
│   └── extract_report.py         # 报告提取脚本（处理中文路径 / 乱码 / 新旧格式）
├── assets/
│   └── template.html             # 填充好的参考模板（数据看板风）
└── references/
    └── design-system.md          # 视觉设计系统文档（配色 / 排版 / 布局节奏）
```

---

## 七、依赖

- Python + `pandas`
- 旧版 `.xls` 需要 `xlrd`，新版 `.xlsx` 需要 `openpyxl`
- 缺少时执行：`pip install pandas xlrd openpyxl`
