# Layer 5 能力层（Skills）实现总结

> 完成日期：2026-07-30
> 需求：为 agent_memory_system harness 添加"加载并执行 skill"的能力
> 范围：仅 Web 端（serve.py + index.html），不改 CLI（agent.py）

---

## 一、目标

在原有四层记忆之上新增"能力层（Layer 5）"，对齐 Claude Code 的 **LLM 主动调用** 模式：

- 由 LLM 自主决定何时加载 skill（非 slash 命令、非语义自动注入）
- 每个 skill 存为子目录 `memory/skills/<name>/SKILL.md`（frontmatter + 正文 + 可选资源脚本）
- LLM 不仅能读取 skill 指令，还能**执行 skill 脚本**（通过完整的 tool-use 多轮循环）
- 任何 skill / 脚本环节异常都不得中断主对话链路（优雅降级）

---

## 二、核心机制

### 渐进式披露（Progressive Disclosure）
- `list_skills()` → 仅返回 name + description（轻量，注入 system prompt）
- `load_skill(name)` → 选定后才读取完整正文

### Tool-use 多轮循环
`/chat` 从"单次流式 completion"改造为两阶段：

1. **循环阶段（非流式）**：向 LLM 暴露 `load_skill` / `run_skill_script` 两个工具。
   模型发出 tool_calls → harness 执行 → 结果回注 messages → 继续，直到模型不再调用工具。
   循环上限 `MAX_TOOL_ROUNDS = 5`，防死循环。
2. **作答阶段（流式）**：用累积的 messages 做一次 `stream=True` 调用，保留前端逐 token 流式体验。

### 脚本沙箱（教学级，非容器级）
`subprocess.run` + 超时（10s）+ 输出截断（8192 字节）+ 数组传参（无 `shell=True`）。
面向可信作者内容的教学 demo，不做 container / seccomp 级隔离。

### 优雅降级
任何 skill 加载 / 脚本执行异常 → log 后当作"无结果"，主对话照常返回，绝不抛错中断 `/chat`。

## 五、内置示例 Skill

| Skill | 类型 | 说明 |
|-------|------|------|
| `weekly-report` | 纯文本指令 | 无脚本。LLM `load_skill` 读取后按"本周完成 / 进行中 / 下周计划 / 风险"四段结构组织周报 |
| `calculator` | 含脚本 `main.py` | 基于 ast 的安全四则运算求值器，输入表达式分词数组、输出 `expr = result` |
| `flash-card` | 含脚本 `scripts/make_flashcard.py` | 为英语单词生成静态 HTML 学习闪卡（音标/词性/释义/近义词/3条中英例句），并归档数据到 `data/<word>.json` |

### flash-card 适配说明

该 skill 原从 Cursor 迁入，与本 harness 格式不兼容（缺 `run:` 字段、脚本只能读现成 JSON 文件），已做三处适配：

1. **frontmatter**：改为单行 description + 补 `run: scripts/make_flashcard.py`，使行式解析器能识别入口脚本（`run` 支持子目录相对路径）。
2. **脚本入参**：`data` 参数改为**同时接受内联 JSON 字符串**。LLM 现场编好单词数据 → 序列化经 `run_skill_script` 的 args 传入 → 脚本生成 HTML、归档 `data/<word>.json`、stdout 打印路径，契合 tool-use"参数进、结果出"约定。补充了非法 JSON / 缺 word 字段的可读错误退出。
3. **正文**：去掉旧的 `.cursor/skills/...` 路径，改写为"自己编写 JSON 数据 → 用 `run_skill_script` 传内联 JSON"的流程。

## 六、新增 SSE 事件

前端据此可视化 skill 活动：

| 事件 | 触发时机 |
|------|---------|
| `skill_detected` | LLM 调用 `load_skill` |
| `skill_loaded` | skill 正文加载完成（含字符数） |
| `skill_script_start` | LLM 调用 `run_skill_script` |
| `skill_script_result` | 脚本执行完成（含 ok / error / 输出字符数） |

## 七、实现成果

- Agent 具备"能力层"：在四层记忆之外，可按需加载能力指令、执行能力脚本并拿到真实结果。
- 三个可用示例覆盖三条路径：纯文本指令（weekly-report）、无状态计算脚本（calculator）、产出真实文件的脚本（flash-card 生成 HTML 闪卡）。
- 前端实时可视化 Layer 5 活动（紫色行 + skill 活动面板）。
- 普通对话零额外开销：不触发工具时第一次调用即返回文本；任何 skill 环节异常都优雅降级，主对话不中断。
