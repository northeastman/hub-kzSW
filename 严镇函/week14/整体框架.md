# 基于 Skill Engineering 的大模型 Agent 能力优化实验项目框架

## 1. 项目名称

基于 Skill Engineering 的大模型 Agent 能力优化研究

通过设计、优化和评估 Skill 文件，研究 Skill 对大模型 Agent
执行效率、Token 消耗和任务质量的影响。

------------------------------------------------------------------------

## 2. 项目背景

随着大语言模型（LLM）的发展，Agent逐渐具备：

-   任务规划
-   工具调用
-   执行反馈
-   经验复用

等能力。

传统 Prompt 或简单 Agent 存在：

-   重复推理
-   Token 消耗较高
-   执行流程不稳定
-   经验无法复用

等问题。

Skill 作为一种经验固化机制，可以将成功任务流程进行抽象：

任务执行

↓

经验总结

↓

Skill保存

↓

后续任务复用

从而提升 Agent 的稳定性和执行效率。

------------------------------------------------------------------------

# 3. 项目目标

设计一个 Skill。

然后通过大模型对 Skill 进行优化。

比较优化前后的效果。

主要评价指标：

## Token 消耗

比较完成相同任务需要消耗的 Token 数量。

## 执行效率

比较：

-   完成时间
-   推理步骤数量
-   工具调用次数

## 输出质量

比较：

-   正确性
-   完整性
-   可用性

方式：

-   人工设计 Skill

示例：

要求模型：

包含：

-   教学流程
-   反馈机制
-   评价方法

Skill V1

例如：

任务：

  指标         结果
  ------------ ------
  Token数量

  任务完成度   

------------------------------------------------------------------------

# Step 3：Skill优化

让大模型优化 Skill。

优化方向：

## 方向1：Token优化

目标：

减少模型输入输出消耗。

方法：

-   删除重复规则
-   合并相似指令
-   简化描述
-   提高规则密度

------------------------------------------------------------------------

## 方向2：执行效率优化

目标：

减少 Agent 无效执行。

方法：

-   减少重复推理
-   优化任务流程
-   增加决策规则

------------------------------------------------------------------------

## 方向3：结果质量优化

目标：

提高任务完成效果。

方法：

-   增加错误检测
-   增加反馈机制
-   增加自我修正流程

------------------------------------------------------------------------

------------------------------------------------------------------------

目标：

评价：

评价：

-   最终结果
