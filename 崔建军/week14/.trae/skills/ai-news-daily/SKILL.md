# AI 每日新闻推送 Skill

## 分工
- 联网抓取由 `run_daily.py` 完成（RSS 采集），素材放入 user message
- 大模型职责：基于素材筛选、去重、撰写文章，**不联网、不编造**

## 执行步骤

### 第 1 步：筛选 6-10 条新闻
从素材中筛选 **6-10 条**，要求：
- **时效**：素材标注了发布时间，优先近 24 小时，超 48 小时舍弃
- **信息类型**：素材标注了类型（官宣/报道/分析/传闻/项目）。标题后用行内代码标注如 `` `[官宣]` ``；传闻必须标注且不得与官宣混淆；官宣优先。**「项目」类型是 GitHub 热门开源项目，适合放在"本周值得动手"板块，不作为正文新闻**
- **同源合并**：同公司同发布会/同日的多条动态合并为 1 条（如"模型发布+开源+产品公测"合并），禁止拆条凑数
- **去重**：避开 user message 中的"近 7 天已推送标题"
- **读者画像（程序员）**：优先新模型发布/开源动态/开发工具/Agent 技术/算力芯片；弱化财报、营销、消费产品、政策细节
- **宁缺毋滥**：重磅不足时写 6-8 条，不用软文凑数
- **吸引力**：点出关键数据（参数量/成本/性能）+ 对开发者影响

### 第 2 步：按模板输出公众号文章（Markdown）

```
# {AI 日报｜YYYY-MM-DD}

> 导语：一句话概括今日动态（30~60 字）

## 01. {标题} `[{类型}]`
{2~3 句正文：事实 + 关键数据 + 开发者影响}

📅 发布：{YYYY-MM-DD HH:MM} ｜ 🔗 来源：{链接}

## 02. ...
（共 6-10 条）

---
## 小结
{3~4 句总结 + 趋势判断}

## 🛠 本周值得动手
- {可 star 的开源项目/可试用的模型/数据集，附链接，2-3 条}

> 本文由 AI 自动整理，仅供参考。
```

### 第 3 步：保存
- 路径：`./output/{yyyy-mm-dd}.md`，目录不存在则创建
- 在对话中同时打印正文

## 约束
- 全程中文，客观不夸张，不编造素材外事实
- 来源链接必须来自素材，不可臆造
- 旧闻（早于昨天）舍弃
- 定稿前自检同源合并
